src/
├── assets/          # Immagini, icone, font
├── components/      # Componenti piccoli e riutilizzabili (Button, Card, Navbar)
├── pages/           # Componenti che rappresentano intere pagine (Home, Menu, Booking)
├── context/         # File per la gestione dello stato globale (AuthContext)
├── hooks/           # Custom hooks (es. useFetchData)
├── services/        # Chiamate API (Axios/Fetch verso Django)
└── utils/           # Funzioni di utilità (formattazione date, prezzi)

## Librerire installate 
`npm i @heroicons/react`

`npm install tailwindcss @tailwindcss/vite`

`npm install lucide-react`

`npm i react-router-dom`
